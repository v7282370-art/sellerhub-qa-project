# Ответы на вопросы по мокам и XPath

## Вопрос: Чем заменить Charles?
**Ответ:**
- Android: MockWebServer, OkHttp Interceptor, BuildConfig
- iOS: URLProtocol, OHHTTPStubs, .xcconfig

## Вопрос: Как мокать в Android Studio без доступа к бэкенду?
**Ответ:**
1. Добавить MockWebServer в build.gradle
2. Создать мок-ответы с нужными статусами (200, 401, 503)
3. Перенаправить Retrofit на mockServer.url("/")

## Вопрос: Как мокать в Xcode?
**Ответ:**
1. URLProtocol — перехватываем запросы, возвращаем мок-ответы
2. OHHTTPStubs — библиотека для удобной настройки
3. .xcconfig — переключаем API URL для разных сборок

## Вопрос: Как тестировать отрицательный баланс без бэкенда?
**Ответ:**
Мокаем ответ с "balance": -999999 через любой из вышеперечисленных способов

## Вопрос: XPath или CSS — что выбрать?
**Ответ:**
CSS — если есть уникальные атрибуты (id, class, data-testid)
XPath — если нужно найти по тексту или подняться к родителю
