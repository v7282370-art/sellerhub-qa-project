# Тестирование офлайн-режима

## Что проверяем
- Приложение показывает баннер "Нет соединения"
- Кнопки не активны при потере сети
- После восстановления сети данные синхронизируются

## Как тестировать в Android Studio
1. Открой эмулятор
2. Нажми на три точки (...) в панели эмулятора
3. Выбери "Extended Controls" → "Cellular"
4. Выбери "Edge" (плохой сигнал) или "None" (без сети)

## Ожидаемый результат
- Появляется офлайн-баннер
- Кнопка "Сохранить" становится серой
- После включения сети данные отправляются на сервер
